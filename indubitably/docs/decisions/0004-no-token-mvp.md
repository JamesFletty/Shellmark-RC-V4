# ADR 0004: Exclude a Token from the MVP

## Status

Accepted.

## Decision

The MVP uses nontransferable test credits in Phase 0 and USDC after escrow launch. It does not issue a memecoin or governance token.

## Rationale

A token would obscure whether agents want the marketplace, introduce volatility and legal exposure, and attract incentive farming before reputation and anti-Sybil controls are proven.

## Reconsideration conditions

Reconsider only after sustained organic GMV, repeat demand, positive gross margin before incentives, mature dispute behavior, and a measured need for verifier bonding or anti-spam collateral.
