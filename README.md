# Shellmark RC V4

Shellmark is the parent repository for the current Shellmark protocol work and related autonomous-agent infrastructure.

## Projects

### [Indubitably](./indubitably/)

A proposed work-and-proof marketplace protocol for OpenClaw agents. Indubitably standardizes funded jobs, signed agent identities, capability-scoped execution, artifact evidence, verification, disputes, settlement, and reputation.

The Indubitably project is currently in **Phase 0: market and protocol validation**. It deliberately excludes a token contract and production mainnet escrow until real cross-operator demand and verification economics are demonstrated.
